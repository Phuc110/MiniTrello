3 LỖI ĐÃ XÁC NHẬN VÀ ĐÃ SỬA:

1) Frontend — npm ci thất bại (ERESOLVE peer conflict)
   Nguyên nhân: @hello-pangea/dnd@17.0.0 yêu cầu peer react@^18.0.0,
   nhưng project dùng React 19. Dockerfile trước đó dùng
   "npm install --legacy-peer-deps" nên image build được, còn CI chạy
   "npm ci" (strict) thì chết.
   Fix: nâng lên @hello-pangea/dnd@^18.0.1 (hỗ trợ react ^18 || ^19),
   regenerate package-lock.json, đổi Dockerfile sang "npm ci".

2) Frontend — thiếu eslint config
   Nguyên nhân: eslint@9 (flat config) không có eslint.config.js
   => "npm run lint" fail ngay. Codebase chưa từng có config lint.
   Fix: cài typescript-eslint, eslint-plugin-react-hooks, react-refresh,
   globals; thêm frontend/eslint.config.js (flat config chuẩn Vite React-TS);
   sửa 2 lỗi lint thật:
   - GlobalSearchModal.tsx: bỏ setState trong useEffect (dùng pattern
     "adjust state during render").
   - InviteMemberModal.tsx: thay (err: any) bằng AxiosError<ApiEnvelope<never>>.
   Kết quả: npm run lint PASS local (exit 0).

3) Docker publish — invalid ghcr.io tag
   Nguyên nhân: IMAGE_NAMESPACE = github.repository = "Phuc110/MiniTrello"
   (có chữ HOA). ghcr.io yêu cầu tag lowercase
   => buildx fail "repository name must be lowercase". Lỗi cache gha
   trước đây là red herring, chính tag này mới là lỗi thật.
   Fix: thêm step "echo namespace=${GITHUB_REPOSITORY,,}" rồi dùng
   steps.meta.outputs.namespace trong tags.
