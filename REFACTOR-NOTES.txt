## 1. Architecture Summary

```
OLD (5 levels):  Workspace → Project → Board → List → Task
NEW (3 levels):  Workspace → Board → List → Task
```

**Stack:**
- Backend: Spring Boot 3.3, Java 21, MySQL 8.4, Flyway, Redis
- Frontend: React 19, TypeScript, Vite 6, Tailwind, React Query, @hello-pangea/dnd
- Infra: Docker Compose (4 containers: mysql, redis, backend, frontend)
- Project root: `D:\Desktop\CSE 456 FInal Project`

**Key design decisions:**
- Plain FK columns (no JPA @ManyToOne relations between domain entities)
- Domain repository interfaces → JPA impl layer
- Soft delete on Workspace, Board, BoardList, Task via `SoftDeletableEntity` + `@SQLRestriction("deleted_at IS NULL")`
- Position-based ordering via lexicographic fractional indexing (`PositionGenerator`)
- `BoardAccessResolver` does 2-hop lookup: BoardList → Board → Workspace for auth
- Auto-generates 3 default lists ("To Do", "In Progress", "Done") when creating a board

## 4. Complete API Endpoints

### Auth
- `POST /api/auth/register`
- `POST /api/auth/login`
- `POST /api/auth/refresh`
- `GET  /api/auth/me`

### Workspaces
- `GET    /api/workspaces` — list my workspaces
- `POST   /api/workspaces` — create workspace
- `GET    /api/workspaces/{id}` — get workspace
- `DELETE /api/workspaces/{id}` — soft-delete workspace (owner only, cascades)
- `GET    /api/workspaces/{id}/members` — list members
- `POST   /api/workspaces/{id}/members` — invite member
- `DELETE /api/workspaces/{id}/members/{userId}` — remove member

### Boards
- `POST   /api/workspaces/{workspaceId}/boards` — create board (auto-creates 3 lists)
- `GET    /api/workspaces/{workspaceId}/boards` — list boards
- `GET    /api/boards/{boardId}` — get board
- `DELETE /api/boards/{boardId}` — soft-delete board

### Board Lists
- `POST   /api/boards/{boardId}/lists` — create list
- `GET    /api/boards/{boardId}/lists` — list lists
- `PATCH  /api/board-lists/{boardListId}/position` — reorder list
- `DELETE /api/board-lists/{boardListId}` — soft-delete list

### Tasks
- `GET    /api/tasks/my-tasks` — all tasks assigned to current user
- `POST   /api/board-lists/{boardListId}/tasks` — create task
- `GET    /api/board-lists/{boardListId}/tasks` — list tasks (supports ?search=)
- `GET    /api/tasks/{taskId}` — get task
- `PUT    /api/tasks/{taskId}` — update task
- `DELETE /api/tasks/{taskId}` — soft-delete task
- `PATCH  /api/tasks/{taskId}/position` — move/reorder task
- `POST   /api/tasks/{taskId}/assignees/{userId}` — assign user
- `DELETE /api/tasks/{taskId}/assignees/{userId}` — unassign user
- `POST   /api/tasks/{taskId}/tags/{tagId}` — add tag
- `DELETE /api/tasks/{taskId}/tags/{tagId}` — remove tag

### Tags
- `POST /api/workspaces/{workspaceId}/tags` — create tag
- `GET  /api/workspaces/{workspaceId}/tags` — list tags

### Notifications
- `GET    /api/notifications` — list all
- `GET    /api/notifications/unread` — list unread
- `PATCH  /api/notifications/{id}/read` — mark read
- `PATCH  /api/notifications/read-all` — mark all read
